    Audio Library Tagger¶

    AI-powered local audio catalogue with a browser search UI. Scans your entire audio library, runs sound event classification (PANNs) and music feature extraction (librosa), then stores everything in a local SQLite database you can search instantly in your browser.

    No data leaves your PC. Everything runs locally.

    📖 Full documentation: https://ludichris000.github.io/Audio-Library-Tagger/ 🛒 Get it on Gumroad: https://chrisburns3d.gumroad.com/l/kaxvx 💬 Discord: https://discord.gg/DSUd2QcyHZ

    What it tags¶

    Tag type Examples
    Sound events Explosion, Rain, Footstep, Piano, Dog, Thunder, Gunshot…
    Category Sound effect / Music / Ambience
    Type One-shot / Short clip / Loop-stem / Full track
    Tempo Very slow / Slow / Medium / Fast / Very fast
    Energy Quiet / Medium energy / Loud
    Mood Bright / Dark
    Texture Tonal / Noisy / Warm / Bright
    Key e.g. A minor, D major
    BPM Estimated tempo

    Requirements¶

    • Python 3.10+
    • NVIDIA GPU with CUDA (recommended — CPU works but is much slower)
    • ~2 GB disk for PANNs model (downloaded once on first run)

    Setup¶

    1. Install PyTorch with CUDA¶

    Find your CUDA version: 

    nvidia-smi

    Install PyTorch (replace cu121 with your version — cu118, cu121, cu124 etc): 

    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

    2. Install dependencies¶

    cd audio_tagger
pip install -r requirements.txt

    3. Download PANNs model (Windows — run in PowerShell)¶

    New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\panns_data"

Invoke-WebRequest -Uri "https://raw.githubusercontent.com/qiuqiangkong/audioset_tagging_cnn/master/metadata/class_labels_indices.csv" -OutFile "$env:USERPROFILE\panns_data\class_labels_indices.csv"

Invoke-WebRequest -Uri "https://zenodo.org/record/3987831/files/Cnn14_mAP%3D0.431.pth" -OutFile "$env:USERPROFILE\panns_data\Cnn14_mAP=0.431.pth"

    The model is ~400 MB and only needs to be downloaded once.

    Usage¶

    Step 1: Scan & tag your library¶

    python tagger.py --path "D:\Audio\MySoundLibrary"

    Options: 

    --path      Path to your audio folder (scanned recursively)
--workers   Parallel workers (default: 1 — keep at 1 for GPU)
--db        Custom database path (default: audio_library.db in same folder)

    The tagger is resumable — if you stop it and restart, already-analysed files are skipped. Run it on new files any time to update the library.

    Progress is logged to the terminal and to tagger.log.

    Step 2: Start the web app¶

    python app.py

    Open http://localhost:5000 in your browser.

    Searching¶

    • Free text search: type any word — matches filenames and all tags
    • Sidebar filters: click any category, type, tempo, energy, or mood to filter
    • Tag pills on cards: click any tag pill to filter by that value
    • Duration filter: filter by minimum/maximum duration in seconds
    • Play preview: click the play button on any file to preview in-browser
    • Open folder: opens the file location in Windows Explorer / Finder
    • Copy path: copies the full file path to clipboard

    File formats supported¶

    WAV, MP3, FLAC, OGG, AIF, AIFF

    Performance notes¶

    • GPU (CUDA): ~1–2 seconds per file (tested on RTX 2070 8GB)
    • CPU (single worker): ~30–60 seconds per file
    • CPU (4 workers): ~15–20 seconds per file (use --workers 4)
    • A library of 10,000 files takes roughly 4–8 hours on GPU (run overnight)
    • Once tagged, searching is instant
